# Teammate and faculty setup

The handoff includes the **already-trained interval-censored v2.4 model**, application,
exact prediction checks, source, configuration and aggregate research evidence.
You do not need PATH files, processed participant histories, a GPU or API keys to
run the active app and its current-model tests.

## Run

Use **Python 3.13**, preferably the tested **3.13.5**, and open a terminal in the
folder containing `run_app.py`. Do not rename or edit fingerprinted model/config
files before running the checks.

### Linux / macOS

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-app.txt
.venv/bin/python run_app.py
```

### Windows PowerShell

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-app.txt
.venv\Scripts\python.exe run_app.py
```

Open **http://127.0.0.1:8501**. The launcher verifies dependency versions, the
included model's fingerprints, and probabilities/timings/explanations for five
fictional regression profiles before starting the app. To use another port,
append `--server.port 8502` to the launcher command.

The dependency list is CPU-only and excludes the archived XGBoost/SHAP/CUDA
research dependencies. Installation requires internet access unless packages
are provided locally. A fresh installation on Windows/macOS has not been
verified; the clean handoff was tested with the existing Linux environment.

## Verify without launching a server

```bash
.venv/bin/python scripts/verify_runtime.py
.venv/bin/python -m pip install -r requirements-test.txt
.venv/bin/python -m pytest tests/test_study_v2_4.py tests/test_longitudinal_app.py tests/test_runtime_handoff.py -q -p no:cacheprovider
```

Use the Windows interpreter path above when appropriate. The complete current
suite tests the active model and interface without raw data. You can also run
`python -m pytest -q -p no:cacheprovider` with the chosen environment interpreter.
`scripts/verify_longitudinal_v2_4.py` is the full research verifier: it requires raw
PATH files and the processed cohort, unlike `verify_runtime.py`.

Restored research code/tests and older reports are included for development and
faculty reference. They do not change the active model. Historical tests opt in
with `--research-tests`; some need separately restored private v1 artifacts and
research dependencies. Use [the research guide](docs/RESEARCH_GUIDE.md) and
[current faculty guide](docs/faculty_guide.md), not old v1 metrics, to present
the current application.

## Included prediction bundle

`artifacts/longitudinal_v2_4/model.json` is the trained v2.4 model as plain JSON:
coefficients, preprocessing parameters and a 128-row *synthetic* explanation
background (independent draws from training marginals). It contains no
participant rows, PERSONIDs, raw survey files or histories, and no pickle is
loaded. Retraining from PATH files reproduces it byte-for-byte.

The `.gitignore` exception permits **only this one current model**, not the rest
of `artifacts/`. `.gitattributes` preserves binary data and fingerprinted source
and dictionary bytes across Git checkouts. Include both hidden files when
uploading. No Git commit, push, public publication or deployment is performed
by the handoff tools.

With matching code/model/dependencies, fictional example predictions must match
within the checker's numerical tolerance. Actual new-person accuracy and actual
month-of-resumption precision are not established by successful setup checks.

## Troubleshooting

| Problem | Action |
|---|---|
| Model missing after download | Check that `artifacts/longitudinal_v2_4/model.json` was included in the repository/archive. |
| Dependency mismatch | Use the same virtual environment for install, checks and launch; install `requirements-app.txt`. |
| Fingerprint mismatch | Restore the complete original bundle, including configs and metadata dictionaries. Do not edit checksums to force a pass. |
| Prediction regression mismatch | Stop and check Python/dependency versions and bundle integrity. Do not retrain to imitate expected values. |
| Port already occupied | Launch with `--server.port 8502`. |
| Full cohort verification needs missing files | `verify_longitudinal.py` needs the raw PATH files and processed cohort; `verify_runtime.py` and the current test suite do not. |

The ZIP generated by `scripts/build_handoff.py` includes `HANDOFF_MANIFEST.json`
with SHA-256 digests for every packaged file. Raw data, processed histories,
secrets, environments, caches and all other model runs remain excluded.
